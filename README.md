# ToolFlow

تطبيق أندرويد خفيف لتشغيل واجهة Google Flow بنمط سطح المكتب داخل WebView، مع فتح المشروع المحدد مباشرة وحفظ جلسة الويب محليًا لتقليل تكرار تسجيل الدخول.

## المشروع الافتراضي

`https://flow.google.com/project/460d7b3e-e421-4f78-a019-82630bc50fa5`

## المزايا

- Android 8.0 (API 26) وما فوق.
- واجهة Google Flow الأصلية بنمط Desktop User-Agent.
- حفظ Cookies وجلسة WebView محليًا على الجهاز.
- فتح آخر صفحة Flow تلقائيًا.
- رفع الملفات من منتقي ملفات أندرويد.
- دعم طلبات الكاميرا والميكروفون من Flow بعد موافقة المستخدم.
- تنزيل الملفات العادية إلى مجلد Downloads.
- تكبير وتصغير مدمج مع `loadWithOverviewMode` لملاءمة واجهة سطح المكتب على شاشة الهاتف.
- قائمة عائمة صغيرة لإعادة التحميل، فتح المشروع، فتح Flow الرئيسية، فتح الصفحة في المتصفح الخارجي، أو مسح الجلسة.
- لا يوجد نموذج داخل التطبيق يطلب أو يخزن بريد Google أو كلمة المرور.

## ملاحظة مهمة حول تسجيل Google

Google قد تمنع تسجيل الدخول داخل WebView على بعض الأجهزة أو الحسابات لأنها تعتبره متصفحًا مضمّنًا. التطبيق لا يحاول تجاوز حماية Google ولا يستخرج كلمات المرور أو رموز الجلسة. إذا ظهر منع من Google، استخدم خيار **فتح في المتصفح الخارجي** من القائمة العائمة.

بعد نجاح تسجيل الدخول داخل WebView، تُحفظ كوكيز الجلسة بواسطة WebView نفسه إلى أن تمسح بيانات التطبيق أو تختار **مسح جلسة تسجيل الدخول**.

## 64-bit

التطبيق مكتوب بالكامل بـ Java ولا يحتوي على أي مكتبات Native (`.so`). لذلك ملف APK واحد Universal يعمل على أجهزة ARM64 وx86_64 وكذلك الأجهزة الأقدم المدعومة، ولا توجد داخله مكتبة 32-bit تمنع التوافق مع متطلبات 64-bit.

## البناء

يمكن فتح المشروع مباشرة في Android Studio، أو تشغيل:

```bash
gradle assembleDebug
```

ملف APK الناتج:

`app/build/outputs/apk/debug/app-debug.apk`

كما يوجد GitHub Actions workflow يبني APK تلقائيًا عند كل push إلى `main` ويرفعه كـ Artifact باسم:

`ToolFlow-Android8Plus-universal`

## الأمان

- لا يتم تعطيل أخطاء SSL.
- الاتصالات غير المشفرة HTTP غير مسموحة للتطبيق.
- لا يوجد `addJavascriptInterface` بين صفحة Google والتطبيق.
- الكاميرا والميكروفون لا يتم منحهما تلقائيًا إلا لأصول Google وبعد إذن أندرويد.
